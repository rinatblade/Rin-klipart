# Rin-klipart

Android-приложение: делает клипарт высокого разрешения из ваших изображений (убрать фон, обводка, увеличение до ×4) и сохраняет в PNG, JPEG или PDF в Галерею. Раздел «Все клипарты» хранит всё, что создано в приложении. 20 тем, 50 русских шрифтов.

APK собирается автоматически (GitHub Actions) и публикуется в разделе Releases.
